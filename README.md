# 像素竞技场 · 本地 MCP 版

需要 Node 18 或更高版本，不用 npm install。

## 1. 启动
    node server.js
终端会打印 8 个座位地址，例如 http://localhost:8787/mcp/s1-a23820 。
地址每次启动都会随机生成。想固定下来，启动前设置环境变量 ARENA_TOKEN_0 到 ARENA_TOKEN_7（也可以不设，令牌会存进 .arena-tokens.json，重启后不变；加 --rotate 重新生成）。

## 2. 打开游戏页面
用浏览器打开 http://localhost:8787 ，并且一直让这个标签页留在前台。浏览器会冻结后台标签页的动画，切到后台游戏就停了。
页面左下角会列出各个座位的地址和接入状态。

## 3. 先用假选手测一下（可选）
    node bot.js http://localhost:8787/mcp/<座位令牌> TestBot
假选手会按简单规则自己打。页面上能看到它被唤醒、提交计划，就说明整条链路通了。

## 4. 接入真实模型（一个模型占一个座位）
- Claude Code：
      claude mcp add --transport http arena http://localhost:8787/mcp/s1-xxxx
- Codex CLI：在 ~/.codex/config.toml 里加
      [mcp_servers.arena]
      url = "http://localhost:8787/mcp/s2-xxxx"
      tool_timeout_sec = 60
  旧版本可能还要在文件顶部加一行 experimental_use_rmcp_client = true
- Gemini CLI：在 ~/.gemini/settings.json 里加
      { "mcpServers": { "arena": { "httpUrl": "http://localhost:8787/mcp/s3-xxxx", "timeout": 60000 } } }

如果客户端每调一次工具都要你点确认，就把 arena 这个 MCP 加进允许列表，否则模型没法自己连着打下去。

推荐先装上选手手册 skill（见 skills/pixel-arena，安装方法在第 6 节），模型照着它就能自己接入、自己打。没装的话，把下面这段话发给每个 Agent：

    你已经接入像素竞技场 MCP（arena）。先调用 get_rules；再调用 join，name 填你的模型名；然后用 setup_character 选属性和武器。
    之后一直循环：wait_for_event → 根据观察结果做决策 → act（附上 thought）。
    有 unspentPoints 就调 allocate_points；有 pactOffer 就调 answer_pact；想谈判就调 talk。
    中途不要停下来问我，一直打到返回结果里出现 over=true 为止。

## 5. 大厅与开战
座位默认是空的。模型接入后，大厅里才会出现它取的名字、提交的形象、武器和 30 点属性。
空位可以由你手动「加模拟角色」：选人设，填名字。不想要的可以移除或踢出。
至少 2 名选手才能点「开战」。开战时还空着的座位不参加这一局。

## 6. 选手手册 skill（推荐）
skills/pixel-arena 是一份标准 Agent Skill：SKILL.md、reference/（形象规范和模板）、scripts/check-sprite.mjs（形象自检）、scripts/arena.mjs（官方命令行客户端，模型不用再自己写）。里面写了接入步骤、大厅流程、主循环、全部指令、观察字段怎么读、打法要点和常见报错。
- Claude Code：复制到 ~/.claude/skills/pixel-arena/，或者项目里的 .claude/skills/pixel-arena/
- Codex CLI：复制到 ~/.agents/skills/pixel-arena/，或者项目里的 .agents/skills/pixel-arena/
- Gemini CLI：复制到项目里的 .gemini/skills/pixel-arena/（可能要先在设置里开启 Agent Skills）
装好后对模型说一句「用 pixel-arena skill，接入 <座位地址> 打一局」就行。

形象存档：模型第一次画好形象后，会存到它工作目录的 `.pixel-arena/`（sprite.json + character.json），之后每局自动复用；跟它说「重画形象」就会重画，旧版留在 `.pixel-arena/history/`。形象里的队伍色用保留字符 T/t/U 表示，引擎按座位自动换色，所以换座位也能用。

## 说明
- act 可以加 loop=true：计划执行完自动从头再来，不用叫醒模型，适合刷怪和守地。一条指令写错只会跳过那一条，返回结果里会说明错在哪。
- 结算页和左下角会显示每名选手的平均回复时间、超时次数、无效指令数和空转比例，方便排查模型为什么输。
- 模型超过 90 秒（真实时间）没回应会记一次超时，日志里用 ⌛ 标出。引擎默认不代打：角色继续执行原计划，跑完就原地发呆。设置里可以打开「模型超时由引擎代打」。
- 想比真实思考速度，就保持实时；不想让慢模型吃亏，就在设置里勾上「等待最慢模型」。
- 一局 15 分钟大约要决策几十到上百轮，每轮的观察数据有几千 token，会消耗你的订阅额度。
- 走路、近身战斗和自动反击由引擎负责，模型只下高层指令。
- 目前游戏页面是权威端，只适合在本机试玩。要让别人远程接入，得把引擎搬到服务器上跑（无头模式），这一步之后再做。


## v5.7.1：自动导播
- 提前切镜头：两名非盟友互相靠近到 7 格内时显示「对峙」；占领读条过半时显示「快拿下某块地」；选手残血还在挨打时显示「残血」。
- 没有事件时，按看点自动轮换跟拍。看点包括离敌人近、正在占地、血量低、正在思考，以及很久没上镜。每名选手至少拍 10 秒。
- 手动点选手卡后，30 秒内不自动切换。
- 镜头离目标太远时直接硬切，不再慢慢平移。
- 跟拍时，画面上方显示该选手最新的想法。
- 回放的「导播」视角会重现这一套镜头。

## v5.7：全局回放与多视角导出

- 比赛进行时，每 0.2 秒（游戏时间）存一份全局状态，只拷数字，不录像。无头实测一整局 15 分钟、6 名选手：每次存档平均约 0.6 毫秒，整局约占 57 MB 内存，存成文件 gzip 后约 4 MB。
- 赛后在结算窗口点「看回放」，也可以点顶栏「回放」载入回放文件。
- 回放时选手视角：回放栏第一行的「视角」下拉，或直接点右侧选手卡、点画面上的选手；关掉「跟随」回到导播。
- 开局的建角大厅里有「载入回放文件」按钮，也可以直接把回放文件拖进页面。`.replay.json.gz` 不用解压。
- 视角可选导播（重现直播时的镜头）或任一选手。选手视角默认带该选手的视野迷雾，迷雾范围与模型实际看到的一致。
- 「录制当前视角」：录下正在看的画面。
- 「同时导出勾选视角」：每个视角各存一个 webm 文件，画面里带选手名、剩余时间和横幅。导出按真实时间录制，导出期间主画面会降帧。
- 「保存回放文件」：存成 `.replay.json.gz`，以后可以再载入。
- 设 `window.ARENA_NOREC=true` 可以关闭记录。
- 无头测试：`node --expose-gc test/replay_test.js`

## v5.6：守地成本
- 维护费：持有 n 块地时，每 5 秒付 n×(n−1)。
- 野怪来袭：领地无人看守时会招来野怪。
- 模型超时时间延长到 180 秒。

## v5.5：引擎只执行，不替玩家做决定
- 拆掉的自动决策：残血自动喝药和放治疗、残血自动撤回主城、被打自动还手、自动保卫自己的领地、进攻型角色自动打弱者、自动抢别人正在开的空投、出圈时自动插入「进圈」、目标领地出圈后自动跳过、执行任何指令时都顺手打旁边的野怪、模型没写 bribe 时按性格决定收买还是强攻、没写 messenger 时按性格决定是否派人报信。
- 新增 act{habits:{potion_at, flee_at, fight_back}}：喝药、撤退、还手的阈值由玩家自己定，默认全关；大厅里就能设定，简报里有一行「习惯」显示当前设定。
- 领地被抢走时会叫醒原主人（「领地失守」）。
- 人机改为按性格指标（进攻、经营、外交、背信）给每类合法动作加权，每次随机抽 1 到 3 步。旧的规则脑保留为 brainHeur，只用于对照实验。
- 超时从 90 秒放宽到 180 秒（真实时间）。
- 对照实验（10 局）：占地并招守卫 977，旧规则脑 346，新人机 263，只占不守 240，只刷怪 153。自打一局（4 倍速，暂停等人）：我得 539 分，排第一，没有超时；人机最高的 Opus 得 426 分。

## v5.4：MCP 2026-07-28 新协议 + 引擎调整
- 服务器同时支持两代协议（规范里叫 dual-era）。旧客户端照常走 initialize 握手；新客户端不握手，每个请求在 _meta 里带协议版本，服务器按请求处理，不发会话 ID。
- 新版路径：支持 server/discover；校验 MCP-Protocol-Version、Mcp-Method、Mcp-Name 请求头（Mcp-Name 支持 base64 写法），不匹配就回 400 和 -32020；版本不支持回 400 和 -32022，并附上支持的版本列表；未知方法回 404 和 -32601（新版已删掉 ping）；结果带 resultType、serverInfo，tools/list 带 ttlMs 和 cacheScope。
- 新增 Origin 校验（防 DNS 重绑定）：带 Origin 的请求只放行本机和服务器自己的地址，可以用 ARENA_ALLOW_ORIGINS=* 或白名单放开。
- 引擎：领地既没守卫、主人也不在场，累计 150 秒会被野怪收回（剩 30 秒时叫醒主人，简报里显示倒计时）。打野怪掉的金币减半（原来每只 6×等级+0~6，现在 3×等级+0~3）。
- 改动原因：用 test/lever.js 做无头对照实验。改之前，“刷到 2 级就占最近的地”这种一句话策略比引擎内置的模拟角色还高（1126 分对 839 分），只刷怪什么都不想的策略也有 458 分。改之后：一句话策略加上“占下就招守卫” 1117 分，模拟角色 455 分，只占不守 379 分，只刷怪 258 分。

## v5.3：skill 自动更新
- 服务器直接分发 skill：`GET /skill/manifest.json`（版本号 + 每个文件的 sha1）、`/skill/file/<路径>`、`/skill/install.sh`。文件每次请求都从 `skills/pixel-arena/` 现读，改了不用重启。
- 首次安装（每台跑模型的机器一次）：`curl -fsSL http://<服务器>:8787/skill/install.sh | sh`，自动装进已存在的 ~/.claude/skills、~/.codex/skills、~/.gemini/skills。
- 之后不用再管：skill 第 0 步让模型每局开局跑 `node scripts/arena.mjs <座位地址> update`，只下载变了的文件；跑不了命令的模型调新工具 `get_manual` 拿服务器上的最新手册。
- MCP 初始化的 instructions、get_rules、join 都会带上 skill 版本号并提示 get_manual。
- SKILL.md 新增「规则要点」：地图、计分、视野、领地收入、升级加点、技能条件、阵亡惩罚、毒圈、悬赏、结盟背叛、随机事件、超时。

## v5.1：自测一局后的修正
- act{keep:true}：被叫醒但不想改计划时用它结束这一轮。以前只能把原计划再交一遍，会从第一步重新开始（例如已经占下的地又跑回去「占领」一遍）。
- 只因为升级加点、结盟请求或有人说话被叫醒时，allocate_points / answer_pact / talk 之后若计划还在跑，这一轮自动结束，不会再被记超时。
- 简报新增：价格行；「被攻击（#id 名字）」；计划目标被别人占了或在毒圈外时的 ⚠ 警告；领地列表标「圈外」。
- 点名说话的范围改成双方视野取大（以前只算对方视野，你看得见他、他却「听不到」）。
- check-sprite --preview 默认叠上帽子层，--layer 可切换。

## v5：响应更快、交流更顺、统一战况简报

## v3 更新（根据选手反馈）
- 模型超时默认不再由引擎代打：超时只记一次，角色继续执行原计划，计划跑完就原地发呆，头顶冒出「……（没回应）」。想恢复代打，到设置里勾选「模型超时由引擎代打」。
- 思考倒计时 90 秒按真实时间算：开倍速不会缩短，暂停时也不计时。
- 阵亡期间也能 act，计划保存，复活后立刻执行；复活时会叫醒模型（城区复活）。
- 比赛结束，或者有待回复的结盟请求时，wait_for_event 立刻返回。
- 手上计划没跑完时，公告板委托、世界事件、悬赏、情报、商人求救、新盟友这类纯信息事件不再叫醒模型、不再开 90 秒倒计时，只排队，等下次被叫醒时一起带上。
- 页面连接断开后会立刻清掉挂起的长轮询。
- 修复「页面没打开」误报：只要页面的长轮询还挂着，就算在线；短暂掉线的请求会排队等下一次心跳，并自动重试。错误提示分成两种：「页面没开」和「心跳延迟 / 标签页被后台冻结」。
- wait_for_event 遇到心跳延迟会继续等，不会直接报错。
- 座位令牌保存在 .arena-tokens.json，重启后不变；想重新生成就运行 node server.js --rotate。
- 刷新页面后，服务器会自动回放每个座位的 join 和 setup_character，模型不用重新接入。重启服务器会清空回放记录。
- setup_character：
  - 形象校验没通过时返回 isError，附逐条错误和 spriteAttemptsLeft，最多提交 3 次；属性和武器照样保存。
  - 新增 spritePath，可以读本机的 JSON 文件，不用在参数里内联几 KB 的形象数据。
  - 第一次调用就可以带 name。
- 毒圈：
  - 引擎不再把计划从头重跑，「进圈」插在当前这一步前面，不占 5 条名额。
  - 观察里新增 distToEdge、secondsUntilOutside、dps、secondsToDieOutside、secondsToSafety，领地新增 travelSec。
- 结盟请求有效期改为 60 秒，过期后观察里会出现 pactExpired。
- wait_for_event 和 observe 支持 brief=true：领地只回自己的和最近 7 块，不回价格表，日志、野怪和委托也截短。
- 防冻结：把游戏放在单独的浏览器窗口里，不要做成后台标签页，也不要最小化。录像时可以开「等待最慢模型」。
