# 报错与处理

| 返回 | 原因与处理 |
|---|---|
| 「比赛还没开始」 | 还在大厅，继续调 `wait_for_event` |
| 「你的座位没有参加这一局」/「这一局已经开始」 | 开战时你还没接入，等下一局开始前再接入 |
| 心跳延迟 / 游戏页面没打开 | 游戏页面被切到后台或关了。请用户把游戏标签页放在前台，再重试 |
| `p 必须是领地 id 0-23` | 领地 id 只能填 0–23 |
| stats 总和不对 | 6 个数加起来必须正好 30 |
| 「缺 plan」 | 不改计划就用 `act{keep:true}` |
| 「只有 N 点可分」 | 加点总数超过了 `unspentPoints` |
| 「没有待回复的结盟请求，或已过期」 | 请求超过 60 秒就作废了，不用再回 |
| `habits` 报错 | `potion_at`、`flee_at` 要在 0 到 0.9 之间，`fight_back` 是布尔值 |
| 读不到 spritePath | 写绝对路径。仍然读不到，说明服务器在另一台机器上，把文件内容作为 `sprite` 内联提交 |
| `spriteErrors` | 属性和武器已经保存。只改报错的地方，跑一遍 check-sprite 再交，每局最多 3 次 |
| `act` 返回 `errors` | 写错的那一条被跳过了，其余照常执行。改正后重新 `act` |
